📋 API Endpoints

GET /api/v1/dispatches/

Get list of book dispatches from main center to subcenters

GET /api/v1/books/available/

Get available books that can be dispatched

GET /api/v1/subcenters/

Get list of subcenters where books can be dispatched

GET /api/v1/boxes/

Get coupon boxes with first/last coupon numbers

GET /api/v1/books/

Get coupon books with sequential numbering

POST /api/v1/dispatches/

Create a new dispatch

GET /api/v1/allocations/

Get coupon allocations (with vehicle details)
