📋 Interface Tabs

1. SubCenters Tab

  • ✅ Create new subcenters with code, name, location
  • ✅ Assign managers from available user list
  • ✅ Set capacity limits
  • ✅ Toggle active/inactive status
  • ✅ View subcenter statistics (users, programs, coupons)

2. Pool Vehicles Tab

  • ✅ Add vehicles with registration, make, model, year
  • ✅ Set vehicle type (Car, Van, Truck, Motorcycle, Pickup)
  • ✅ Track fuel type, engine capacity
  • ✅ Manage vehicle status (Active, Maintenance, Retired, Damaged)
  • ✅ Assign to specific subcenters
  • ✅ Track mileage, service dates, insurance
  • ✅ View current driver assignments

3. Drivers Tab

  • ✅ Add drivers with employee ID, personal details
  • ✅ Manage license information and classes
  • ✅ Track license expiry dates
  • ✅ Set driver status (Active, Inactive, Suspended, On Leave)
  • ✅ Assign to specific subcenters
  • ✅ Contact information management
  • ✅ View current vehicle assignments

🔐 Permissions & Access

  • SUPERUSER/ADMIN: Full access to all subcenter management features
  • MAIN_CENTER: Can view and manage subcenters, vehicles, and drivers
  • SUB_CENTER: Limited access based on business requirements
  • Fuel Allocations: Remain in subcenter main pages as requested
