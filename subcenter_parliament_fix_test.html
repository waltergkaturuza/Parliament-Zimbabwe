Issue: Parliament operations not appearing for SUB_CENTER users

Status: ✅ FIXED

🐛 Problem Identified

The parliament operations navigation in UnifiedLayout.tsx was missing SUB_CENTER in the role permission check. Only ['SUPERUSER', 'ADMIN', 'MAIN_CENTER', 'BENEFICIARY'] roles were allowed access to parliament operations.

✅ Solution Implemented

Navigation Permission Update

Updated the role check in UnifiedLayout.tsx to include SUB_CENTER:

// Before (Line 193) if (hasRole(['SUPERUSER', 'ADMIN', 'MAIN_CENTER', 'BENEFICIARY'])) { // After (Fixed) if (hasRole(['SUPERUSER', 'ADMIN', 'MAIN_CENTER', 'SUB_CENTER', 'BENEFICIARY'])) {
